🚀 Java Learning Series | Day 3 – Java Environment Setup
Before writing our first Java program, we need to set up the right development environment.
The Java Development Kit (JDK) is an essential software package that provides all the tools required to develop, compile, and run Java applications. A proper setup ensures a smooth coding experience and helps us avoid common configuration issues.

📌 Key Learnings
✅ JDK (Java Development Kit) is required to write and run Java programs.
✅ JDK includes the JRE (Java Runtime Environment), Java Compiler (javac), debugger, and other development tools.
✅ After installing the JDK, configure the JAVA_HOME and PATH environment variables.
✅ Verify the installation by running: java -version

🌍 Why is this important?
Every Java application starts with a properly configured environment. Setting up Java correctly today saves time and avoids errors while learning advanced concepts in the future.

💡 Quick Revision
JDK = Tools to develop Java applications.
JRE = Runs Java programs.
javac = Compiles Java source code.
java -version = Verifies Java installation.
