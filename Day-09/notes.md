☕ Java Learning Series | Day 9 – Structure of a Java Program
Today, I learned how a basic Java program is structured and understood the purpose of its main components.

💻 Basic Java Program
class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

🔍 Understanding the Structure
1. class Main
Defines a class named Main.
2. main() method
The starting point from where the Java program begins execution.
3. public
Makes the main() method accessible to the JVM.
4. static
Allows the JVM to call main() without creating an object.
5. void
Indicates that the method does not return a value.
6. String[] args
Used to receive command-line arguments.
7. System.out.println()
Displays output on the console.

🔄 Program Flow
Class → main() → Statement → Output

💡 Quick Revision
✔ Class defines the program structure
✔ main() is the entry point
✔ System.out.println() displays output
✔ Statements generally end with ;
✔ { } define blocks of code
