# Day 2 — What is Java?

Java is a high-level, class-based, object-oriented programming language developed by Sun Microsystems (now owned by Oracle). It was officially released in 1995.

## Why Java?
- Simple & Easy to Learn
- Platform Independent — Write Once, Run Anywhere (WORA) using JVM
- Object-Oriented
- Robust & Reliable
- High Performance (JIT compiler)
- Large Community Support

## Real-World Examples
- Android Applications
- Web Applications
- E-Commerce Systems
- Banking Systems
- Enterprise Systems

## Quick Revision
- Java is a high-level, class-based, object-oriented programming language.
- Developed by Sun Microsystems, released in 1995.
- Goal: Write once, run anywhere and build reliable applications.
