🚀 Java Learning Series | Day 8 – JDK, JRE & JVM

Today, I learned about the three important components of the Java platform: JDK, JRE, and JVM.

☕ 1. JDK – Java Development Kit
JDK is used by developers to develop, compile, debug, and run Java programs.
It contains:
Java Compiler (javac)
JRE
Development tools

☕ 2. JRE – Java Runtime Environment
JRE provides the environment required to run Java applications.
It mainly contains:
JVM
Java class libraries
Supporting runtime files

☕ 3. JVM – Java Virtual Machine
JVM is responsible for executing Java bytecode.
It helps Java achieve platform independence because the same bytecode can run on different operating systems with a suitable JVM.

🔄 How Java Works
Java Source Code (.java)
⬇️ javac
Bytecode (.class)
⬇️ JVM

Program Execution
💡 Quick Revision
JDK → Develop Java programs
JRE → Run Java programs
JVM → Execute Java bytecode

📌 Remember:
JDK = JRE + Development Tools
JRE = JVM + Libraries
