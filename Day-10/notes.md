📌 What I Learned
Java programs are made up of small individual units called Tokens.
The main types of Java tokens are:

🔹 Keywords – Reserved words with a special meaning
Example: class, public, static, int
🔹 Identifiers – Names given to classes, methods, and variables
Example: Main, studentName, calculate
🔹 Literals – Fixed values used in a program
Example: 10, 25.5, "Hello", true
🔹 Operators – Symbols used to perform operations
Example: +, -, *, /, ==, &&
🔹 Separators – Symbols used to separate different parts of a program
Example: (), {}, [], ;

💡 Quick Revision
Java is case-sensitive, statements generally end with a semicolon (;), and { } are used to define blocks of code.
