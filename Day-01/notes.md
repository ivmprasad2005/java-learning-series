# Day 1 — What is Programming?

Programming is the process of writing instructions that tell a computer **what** to do, **how** to do it, and **when** to do it.

## Key Takeaways
- Programming is all about solving problems using logic.
- A program is a collection of instructions executed by a computer.
- Programming powers websites, mobile apps, AI, games, and enterprise software.
- We use programming languages like Java, Python, C, C++, etc. to write these instructions.

## Real-World Example
Ordering food on Swiggy/Zomato:
1. You place an order in the app.
2. The restaurant receives it and prepares your food.
3. The delivery partner gets notified and picks it up.
4. You can track the order live until it reaches you.

## Quick Revision
- **Programming** = Giving instructions to a computer.
- **Program** = A set of instructions.
- **Goal** = Solve problems through code and logical thinking.
